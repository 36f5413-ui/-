예시 게시물

처음 접속하면 가상의 문화공간 조성 프로젝트 1건과 가상의 투자기관 1곳, 비공개 연락 요청 예시가 자동 등록됩니다. 실제 기관이나 실제 연락처가 아닙니다.

중요: 이 버전은 서버 없는 브라우저 시연용입니다. 게시물·투자자·연락 요청은 현재 기기의 브라우저 IndexedDB에 저장됩니다. 다른 이용자와 실시간 공유되지 않으며, 비공개 요청도 실제 보안이 보장되는 비밀 메시지가 아닙니다. 실제 서비스에는 로그인, 서버 DB, 파일 저장소, 역할별 접근권한, 암호화, 신고·관리 기능이 필요합니다. 테스트에는 가상 연락처만 사용하세요.
